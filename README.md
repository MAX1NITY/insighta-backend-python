Insighta Labs+ Backend (Python FastAPI)
System Architecture
The Insighta Labs+ platform is built on a high-performance, modular architecture utilizing Python FastAPI as the core backend engine. This transition from Node.js leverages FastAPI’s asynchronous capabilities and native support for Pydantic data validation, ensuring a robust API layer for both the web portal and the CLI tool. Data persistence and authentication services are managed through Supabase, utilizing the supabase-py client for direct database interaction and state management. The ecosystem is completed by a React-based Web Portal and a JavaScript CLI, both of which interface with the backend through a standardized API contract, ensuring that while the "brain" of the system has been rebuilt, the frontend experience remains seamless and consistent.

Authentication Flow
Security is centered around a GitHub OAuth with PKCE implementation, designed to handle both browser-based and terminal-based logins. When a user initiates a login through the CLI, the tool generates a unique state and code_verifier locally and sends both to the backend, which stores them in the auth_state table. For Web Portal users, the flow follows a traditional browser redirect where the code_verifier is omitted. Upon a successful GitHub callback, the backend validates the state and expiry, exchanges the code for a GitHub token, and issues internal JWTs. To maintain security across environments, the Web Portal receives these tokens via HTTP-only, Secure cookies, while the CLI receives them directly in the redirect URL to be stored in the local filesystem.

CLI Usage
The Insighta CLI provides a powerful terminal interface for managing user profiles and system data. Users can authenticate by running the insighta login command, which triggers the PKCE-protected OAuth flow in their default browser. Once authenticated, users can interact with the database using commands like insighta profiles to list data or insighta search "find female users from Australia" to utilize the natural language engine. For administrative tasks, the insighta profiles --export command allows authorized users to download the entire profiles dataset as a CSV, formatted with the strictly required column order for external reporting. All CLI credentials are saved securely at ~/.insighta/credentials.json to enable persistent sessions.

Token Handling
This system implements a strict 3-minute and 5-minute token rotation strategy to minimize the window of opportunity for stolen credentials. The Access Token is valid for exactly 3 minutes, providing short-lived permission to access protected /api/\* routes, while the Refresh Token expires in exactly 5 minutes. Users must hit the /auth/refresh endpoint before the 5-minute window closes to receive a brand-new pair of tokens, a process known as token rotation. This logic is enforced by the utils/jwt.py module using PyJWT and HS256 signing, ensuring that if a user is marked as inactive in the database, their ability to refresh tokens is immediately revoked.

Role Enforcement
Access control is managed through a custom require_role decorator and middleware that validates user permissions on every request. Every user is assigned a role in the Supabase users table, defaulting to analyst for read-only access. Routes like POST /api/profiles or GET /api/profiles/export are strictly protected for users with the admin role. The middleware/auth.py script intercepts incoming requests, extracts the user’s identity from the JWT or cookie, and checks both their role and is_active status. If a user is deactivated or attempts to access an endpoint above their paygrade, the system returns a 403 Forbidden error, preventing unauthorized data modification.

Natural Language Search
The platform features an advanced search capability that allows users to query the profiles table using plain English through the extract_filters utility. This function parses the search string to identify key attributes such as gender, age, and country name, converting them into structured Supabase filter queries. For example, a query like "seniors from TZ" is automatically translated into filters for age_group = 'senior' and country_id = 'TZ'. This approach abstracts the complexity of SQL or API filtering away from the user, providing a "Google-like" experience for data discovery within the Insighta Labs+ ecosystem.
